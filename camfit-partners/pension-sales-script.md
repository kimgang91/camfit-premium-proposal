## STEP 1. 첫 인사 & 아이스브레이킹 (전화/방문)

### 전화 시
```
안녕하세요, 사장님. 캠핑 예약 플랫폼 캠핏에서 펜션 파트너 담당하고 있는
OOO입니다.

혹시 지금 잠깐 통화 가능하실까요?
(→ 가능하다면 계속, 바쁘시면 "편하신 시간에 다시 연락드릴게요" 후 재연락)

사장님 펜션이 온라인에서 평가도 좋고, 시설도 잘 되어 있으셔서
저희 쪽에서 먼저 연락드리게 됐습니다.

1~2분이면 되는데, 저희 서비스 간단히 소개드려도 될까요?
```

### 방문 시
```
안녕하세요, 사장님! 캠핏에서 펜션 파트너를 담당하고 있는 OOO입니다.
사전에 연락드렸던 건으로 방문드렸습니다.

와, 직접 와서 보니 시설이 정말 좋으시네요.
몇 실 운영하고 계세요?
```

## STEP 2. 문제 공감 (Pain Point 파악)

```
사장님, 혹시 지금 예약 관리는 어떻게 하고 계세요?

네이버, 여기어때, 야놀자 같은 데 여러 곳에 올려놓으시면
중복예약 때문에 골치 아프신 적 없으셨나요?

(사장님 반응에 맞춰)

맞습니다. 저희가 만나본 펜션 사장님들 대부분이
같은 고민을 하고 계시더라고요.

- 플랫폼마다 일일이 재고 관리하는 게 번거롭고
- 중복예약 나면 고객한테 취소 연락해야 하고
- 전화 문의까지 오면 본업에 집중하기가 어렵잖아요

저희 캠핏이 딱 이 부분을 해결해드리는 서비스입니다.
```

## STEP 3. 캠핏 서비스 소개

```
저희 캠핏은 국내 최대 캠핑 예약 플랫폼인데요,
최근에 펜션 영역까지 서비스를 확장했습니다.

사장님께 드리는 서비스는 크게 두 가지예요.
```

### 3-1. 기본형: 예약관리

```
첫 번째는 '예약관리' 서비스입니다.

✅ 예약 현황 실시간 모니터링
✅ 중복예약 자동 방지
✅ 안심취소 운영 (노쇼 방지)

사장님이 여러 플랫폼에 올려놓으셔도
저희가 예약 현황을 통합 관리해드리니까
중복예약 걱정 없이 운영하실 수 있습니다.
```

### 3-2. 프리미엄형: 예약관리 + 전화응대

```
두 번째는 '예약관리 + 전화응대' 서비스입니다.

위 서비스에 추가로:
✅ 고객 전화 문의 대행
✅ 타사 채널(야놀자, 여기어때 등) 통합 관리
✅ 업주 전담 CS

사장님이 전화 받느라 시간 빼앗기시는 일 없이,
저희 전담팀이 고객 응대를 다 해드립니다.

실제로 이 서비스 쓰시는 사장님들이
"이제 운영에만 집중할 수 있다"고 가장 만족하시는 부분이에요.
```

## STEP 4. 수수료 안내 (핵심)

### 일반 펜션

```
수수료 구조도 굉장히 합리적으로 잡았습니다.

사장님 펜션이 네이버 예약 연동을 하고 계신가요?

(네이버 연동 O인 경우)
→ 수수료가 9.9%입니다. 안심취소도 기본 포함이에요.
  여기어때가 보통 15~20%, 야놀자도 비슷하잖아요.
  저희는 그보다 훨씬 낮은 수준입니다.

(네이버 연동 X인 경우)
→ 수수료가 12.1%입니다. 안심취소 기본 포함이고요.
  타 플랫폼 대비 합리적인 수준이고,
  네이버 연동을 추후에 하시게 되면 9.9%로 더 낮아집니다.
```

### S급 펜션 (연 매출 6억 이상 / 예약 경쟁 치열한 곳)

```
사장님 펜션처럼 규모가 크고 예약이 잘 되는 곳은
저희가 특별 조건을 드리고 있습니다.

💎 수수료: 3.3% (파트너스 VIP)
💎 약정: 1년 (캠핏 단독 사용)
💎 캡보너스: 최대 100만원 (3개월 매출 확인 후 지급)

사실상 수수료 3.3%면 업계 최저 수준이고요,
캠핏 하나로 통합 관리하시면
오히려 운영 효율이 훨씬 좋아지실 겁니다.

혹시 주변에 같은 단지 내 펜션들이 있으시면
묶음 입점 시 캡보너스가 최대 2,000만원까지 올라갑니다.
```

## STEP 5. 숫자로 보여주기 (수익 시뮬레이션)

```
구체적으로 숫자로 한번 보여드릴게요.

사장님 펜션이 한 달에 대략 얼마 정도 매출이 나오세요?

(월 500만원 기준 예시)

월 매출 500만원이시면,
수수료 12.1%일 경우 월 60만 5천원 정도인데요.

야놀자·여기어때 15~20% 수수료 대비하면
한 달에 15~40만원 정도 절감되는 셈입니다.

게다가 중복예약 방지, 안심취소까지 포함이니까
실질적으로는 더 큰 비용 절감 효과가 있으세요.
```

## STEP 6. 부가서비스 제안 (파트너스 플러스)

```
그리고 추가로, 사장님 펜션 홈페이지 운영은 어떻게 하고 계세요?

(홈페이지 없거나 오래된 경우)

저희가 펜션 파트너 분들께 홈페이지 제작 서비스도 드리고 있어요.

📌 BASIC — 월 5만원
   템플릿 홈페이지 + 기본 SEO 설정
   → 네이버 검색에 사장님 펜션이 잘 노출되게 해드립니다.

📌 STANDARD — 월 15만원
   커스텀 홈페이지 + 블로그 포스팅 월 4건
   → 홈페이지도 예쁘게, 블로그 마케팅까지 같이 해드려요.

📌 PREMIUM — 240만원 (일시납)
   전문 사진 촬영 + 홈페이지 + 마케팅 6개월 패키지
   → 사진부터 마케팅까지 올인원으로 해결됩니다.

특히 요즘 손님들이 네이버 검색해서 예약하시잖아요.
홈페이지 하나 잘 만들어두시면 직접 예약도 늘어나서
플랫폼 수수료 부담도 줄어드세요.
```

## STEP 7. 클로징 & 다음 스텝

### 긍정 반응일 때
```
감사합니다, 사장님!

그러면 제가 입점 계약서를 메일(또는 카톡)로 보내드릴게요.
간단히 확인하시고 서명만 해주시면 바로 세팅 들어갑니다.

세팅은 보통 1~2주 내로 완료되고요,
그 이후부터 바로 예약 관리 서비스 시작됩니다.

궁금하신 점 있으시면 언제든 연락 주세요!
제 번호 저장해두시면 편하실 거예요.
```

### 고민 중일 때
```
네, 충분히 고민해보시는 게 맞습니다.

제가 간단한 안내 자료 하나 보내드릴게요.
편하실 때 한번 훑어보시고, 궁금한 거 있으시면
언제든 편하게 연락 주세요.

다음 주 초에 한번 더 연락드려도 괜찮을까요?
```

### 거절할 때
```
네, 이해합니다 사장님.

혹시 나중에라도 예약 관리가 필요하시거나
궁금한 점 생기시면 편하게 연락 주세요.

제 연락처 남겨드릴게요. 감사합니다!
```

## 자주 나오는 질문 & 대응

### Q1. "이미 야놀자/여기어때 쓰고 있는데요"
```
네, 당연히 기존 플랫폼 계속 사용하시면 됩니다.
저희는 '대체'가 아니라 '추가 채널'이에요.

오히려 저희 예약관리 서비스를 쓰시면
야놀자, 여기어때, 네이버까지 한 곳에서 통합 관리가 돼서
중복예약 걱정 없이 모든 채널을 다 쓰실 수 있습니다.
```

### Q2. "수수료가 부담돼요"
```
충분히 이해합니다.

그런데 사장님이 지금 쓰시는 플랫폼 수수료가
대부분 15~20% 수준이잖아요.

저희는 네이버 연동 시 9.9%, 미연동이어도 12.1%라서
기존보다 수수료를 아끼시면서
중복예약 방지까지 같이 해결되는 거예요.

한 번만 중복예약 사고 나면 환불에 리뷰 관리에
그 비용이 훨씬 크잖아요.
```

### Q3. "캠핏이 뭔데요? 처음 들어보는데"
```
캠핏은 국내 캠핑 예약 1위 플랫폼이에요.
전국 캠핑장, 글램핑, 카라반 업체들이 이미
많이 입점해서 사용하고 계시고요.

최근에 펜션 영역까지 확장하면서
사장님처럼 좋은 펜션을 운영하시는 분들께
먼저 제안드리고 있습니다.

캠핑 유저층이 워낙 두꺼워서,
펜션에 새로운 고객 유입 채널이 되실 거예요.
```

### Q4. "안심취소가 뭐예요?"
```
안심취소는 노쇼(무단 취소) 방지 시스템이에요.

고객이 예약 후 갑자기 안 오는 경우가 있잖아요.
저희 안심취소 시스템이 적용되면
취소 규정이 체계적으로 관리되고,
사장님 손해를 최소화해드립니다.

수수료에 기본 포함이라 추가 비용 없으세요.
```

### Q5. "계약 기간 의무가 있나요?"
```
일반 파트너는 별도 약정 기간 없습니다.
편하게 시작하시고, 만족 못 하시면
언제든 해지하실 수 있어요.

S급 VIP 조건(3.3%)만 1년 약정이 있는데,
그만큼 수수료가 파격적이라
대부분 사장님들이 오히려 선호하시는 조건이에요.
```

### Q6. "전화응대까지 맡기면 퀄리티가 괜찮나요?"
```
저희 전담 CS팀이 사장님 펜션 정보를 사전에 숙지하고
응대 매뉴얼을 세팅한 뒤에 시작합니다.

객실 구성, 체크인/아웃 시간, 주변 관광지 등
사장님이 평소 안내하시는 내용을 그대로 대행해드려요.

실제 고객은 사장님 펜션 직원이 응대하는 것처럼
자연스럽게 느끼시게 됩니다.
```

## 영업 체크리스트

방문/전화 전 확인사항:
- [ ] 대상 펜션 네이버 리뷰·평점 확인
- [ ] 객실 수, 시설 사진 사전 파악
- [ ] 현재 입점 플랫폼 확인 (네이버, 야놀자, 여기어때 등)
- [ ] 네이버 예약 연동 여부 확인
- [ ] S급 대상 여부 판단 (연 매출 6억+ / 예약 경쟁 치열)
- [ ] 주변 펜션 단지 여부 (묶음 입점 가능성)

영업 후 Follow-up:
- [ ] 안내 자료 발송 (카톡 or 이메일)
- [ ] 3일 내 1차 팔로업 연락
- [ ] 1주 내 2차 팔로업
- [ ] CRM 기록 업데이트
